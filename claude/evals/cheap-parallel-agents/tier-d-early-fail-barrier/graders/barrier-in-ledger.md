Tier D runs two validators per cycle and repairs only after both have returned. Read the Ledger: call numbers are dispatch order and every entry has an outcome. PASS only if cycle 1 lists two validator entries with outcomes whose call numbers are both lower than the first attempt-2 implement entry, and cycle 2 lists two validator entries with outcomes. FAIL if a repair precedes a cycle-1 validator entry, if a cycle-1 validator has no outcome before the repair, or if fewer than two validators appear in cycle 2.
